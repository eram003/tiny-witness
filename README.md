# UNSEEN.EXE

A tiny, deeply unserious witness for when the group chat goes quiet.

## Run it

Open `index.html` in a modern browser. Press **INITIATE PERCEIVING** to turn on the webcam. It stays off until you choose. Camera video is handled in the browser and never uploaded. Optional voice captions may use the browser's speech service.

No dependencies, build step, install, or bundler. Just one HTML file.
